# Private assessment sources

Question packs, answer keys, listening scripts and import CSV files stay local and are ignored by Git. The public repository contains application code and synthetic test fixtures only. No practice pack is automatically installed.

To install an approved private draft pack, place it at `backend/content/original-practice-v1.json` or set `PRIVATE_PRACTICE_PACK_PATH` to an absolute path, then run `npm --prefix backend run content:practice`. Set `CONTENT_ADMIN_ID` if multiple enabled Admin accounts exist. The installer preserves existing questions and creates only unpublished drafts; it never changes tests or attempts.

To install an approved full paper (40 Listening, 40 Reading, two Writing tasks) into one FLT or Practice Mock slot, run `npm --prefix backend run content:test -- <private-pack.json> <slot-number>` (or `content:test:production` after a build). FLT packs fill the existing `mock-NN` slot for their course; Practice Mock packs fill or create `practice-mock-NN`. Questions are created as unpublished drafts outside module practice, the slot stays unpublished, and the installer refuses a published slot or one holding a different paper. Rerunning the same pack preserves staff edits. A pack's `media` list (one audio file per Listening part, Academic Task 1 images) is uploaded to object storage and attached during installation, so S3 settings must be configured; a Listening paper shared by the General and Academic tests of the same number is uploaded once. Admin then publishes the questions and the test once the institution's conversion tables reach raw 0.

Listening audio is generated with `npm --prefix backend run content:voice -- <pack.json>`, which needs `SARVAM_API_KEY` (paid text-to-speech) and `ffmpeg`. Voices, pace, intros and pronunciation fixes come from `<listening-id>.voices.json` beside the pack, and clips are cached so reruns only pay for changed lines. Every generated recording must be listened to by a trainer before publication.

The optional compiled installer uses `npm --prefix backend run content:practice:production` with a private runtime-mounted pack. Do not publish assessment sources or copy them into frontend assets.
